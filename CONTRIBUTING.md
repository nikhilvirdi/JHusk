# Contributing

JHusk is not currently accepting external contributions or pull requests.

This is a deliberate choice at this stage of the project, not an oversight. The library is still actively evolving, and keeping the codebase and design decisions in one place makes that easier to do carefully. Issues opened to report a genuine bug are welcome to read, but please don't expect a pull request to be reviewed or merged right now.

This may change as the project matures. If it does, this document will be updated to reflect that.
