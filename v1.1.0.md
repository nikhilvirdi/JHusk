# v1.1.0 - Released

Reference for V, Claude (chat), and Claude Code (agent). All items below are complete.

---

### 1. Deterministic edge-case seed corpus
**Status:** Done
**Touches:** `Property.java`
Before the random example loop in `check()`, runs a small fixed set of deterministic replay-mode `DataSource`s (all-zero buffer, all-`0xFF` buffer) as ordinary examples. All-zero drives every primitive to its D4 shrink target (min/false/empty); all-`0xFF` drives the opposite boundary.

---

### 2. `generationBudget()` on `@Property`
**Status:** Done
**Touches:** `junit/Property.java`, `junit/PropertyExtension.java`
`int generationBudget() default -1;` on the annotation, threaded to `.withGenerationBudget(...)` on the runner when set, mirroring the existing `seed()` pattern.

---

### 3. Docs cleanup
**Status:** Done
**Touches:** `Generators.java` (Javadoc), `FailureStorage.java` (Javadoc)
Documented default bounds for `maps()`/`sets()` and added `.jhusk/` CI guidance (gitignore vs. cache).

---

### 4. Exhaustive `booleans()` + `Generators.exhaustive(T...)`
**Status:** Done
**Touches:** `Generators.java`
`booleans()` already gets full true/false coverage for free from the item #1 edge-case corpus, confirmed with a test. Added `Generators.exhaustive(T...)` for small explicit domains, reusing `oneOf()`'s D3 selector.

---

### 5. `Property.assuming(Predicate<T>)`
**Status:** Done
**Touches:** `Property.java`
Property-level precondition distinct from `filter()`, checked once against the fully-assembled value right before the assertion runs. Rejections count as invalid runs with their own counter, reported separately in the exhaustion diagnostic (overrun-only, assumption-only, filter-only, mixed-cause).

---

### 6. Delta-debugging chunk-removal shrink pass
**Status:** Done
**Touches:** `internal/Shrinker.java`
Hierarchical/binary span removal for sibling `list-element` spans before falling back to one-at-a-time `spanDeletion()`. Fixes a benchmark finding where a 50-element sequence exhausted the shrink-attempt budget and produced a bloated result instead of the true minimum.

---

### 7. Stateful/model-based testing (`Commands` abstraction)
**Status:** Done
**Touches:** New files `Command.java`, `Commands.java`
`Command<Model,Real>` (precondition/nextModel/runAndVerify) and `Commands<Model,Real>` (startingWith/withCommand/asProperty), built entirely on existing `Generators.lists()`/`oneOf()` and `Property.forAll()` -- no changes needed to `Property.java`, `Generators.java`, or the shrinker. Preconditions checked at execution time (skip, not reject), so sequence shrinking inherits item #6's improvement for free. Verified against `IntStack`: passes against the correct implementation, catches and shrinks a deliberately-injected bug in a buggy wrapper.

---

### 8. Banner + pass stats (added beyond original scope)
**Status:** Done
**Touches:** `Property.java`
A once-per-session ASCII banner (suppressible via `-Djhusk.banner=false`) and a per-property pass-stats summary line (examples run, edge-case/random breakdown, invalid-run breakdown by cause) printed on every successful `check()` call.
